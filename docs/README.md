# Documentation map

Start with:

1. `architecture/overview.md` — system boundaries and source-of-truth rules;
2. `evidence/engineering-evidence.md` — research and engineering evidence behind the design;
3. `roadmap/phases.md` — implementation ladder and gates;
4. `operations/local-demo.md` — runnable foundation demonstration;
5. `use-cases/feature-delivery.md` — end-to-end engineering scenario.

Architecture decisions are stored in `decisions/`.

Repository configuration after publication is documented in `development/repository-settings.md`.
