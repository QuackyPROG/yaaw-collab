# Support

YAAW Collab is community-supported.

Use:

- **GitHub Discussions** for design questions and usage discussion when enabled;
- **GitHub Issues** for reproducible defects and scoped feature requests;
- **private vulnerability reporting** for security-sensitive reports.

Before opening an issue, run:

```bash
npm run check
npm run demo
```

and include the Node.js version, operating system, repository revision, and the smallest reproducible scenario.
